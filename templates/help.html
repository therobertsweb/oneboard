ONEBoard

Optimización continua para sitios web

ONEBoard está diseñado para reducir la fricción de mantener un sitio web actualizado. La meta es centralizar análisis, cambios con inteligencia artificial, control de archivos, historial, respaldos y publicación remota para que la actualización constante del sitio sea más rápida, más ordenada y menos riesgosa.

Configuración inicial

  1. Entra a Settings y guarda tu API key de Muse en la sección API de Muse.
  2. En Site Manager, conecta el directorio local del website que ONEBoard puede editar.
  3. Configura el destino remoto SSH/SFTP si el sitio vive en un servidor externo.
  4. Crea un backup antes de cambios grandes o antes de publicar.

Configurar la inteligencia artificial

La IA usa la API key del usuario autenticado. Esto evita que todos los clientes dependan de una sola key del servidor y permite que el consumo se facture a la cuenta correcta.

  1. Crea una API key en tu cuenta de Muse (Meta).
  2. Pégala en Settings -> API de Muse.
  3. Confirma con tu contraseña actual para guardar el cambio.
  4. Desde Site Manager, escribe una solicitud o usa una acción rápida.

Actualizar website con IA

Usa el área AI Website Studio para pedir cambios como actualizar textos, crear secciones, mejorar llamadas a la acción o generar páginas completas. La IA recibe reglas para mantenerse dentro del directorio conectado y respetar el diseño existente.

Si quieres que la IA use una imagen específica, súbela como imagen sugerida o selecciónala desde la biblioteca de assets antes de enviar la solicitud.

Acciones rápidas

Las acciones rápidas generan solicitudes comunes sin tener que escribir desde cero: actualizar el hero, agregar una sección, mejorar el CTA o crear una landing. Puedes usarlas tal cual o escribir instrucciones más específicas en el composer.

Biblioteca de assets

La biblioteca guarda imágenes reutilizables del cliente. Después de subir una imagen puedes usar el botón Usar imagen para que la próxima actualización de IA la tome como referencia.

La IA no publica automáticamente la imagen original desde la carpeta interna. Si decide usarla, debe copiarla a la carpeta pública de assets del sitio y enlazar esa copia.

Explorador de archivos

El explorador permite revisar carpetas, previsualizar archivos de texto e imágenes, elegir imágenes para la IA y eliminar archivos cuando sea necesario. Las rutas se validan para que las acciones no salgan del directorio del sitio conectado.

Historial, diff y restauración

Cada actualización con IA crea un snapshot previo, registra archivos creados/modificados/eliminados y muestra un diff para archivos de texto. Si un cambio no convence, puedes restaurar solo los archivos tocados por esa actualización.

Los estados Pendiente, Aprobado, Publicado y Restaurado ayudan a ordenar el flujo de revisión.

Conexión SSH/SFTP

En Deploy remoto configura host, puerto, usuario, ruta remota y método de acceso. Puedes usar llave SSH o contraseña. Si ya hay una contraseña guardada, deja el campo vacío para conservarla.

Esta configuración prepara el flujo para publicar el workspace local en un servidor remoto de forma controlada.

Windows 11

En Windows 11 ONEBoard se ejecuta con Python y Waitress. Usa scripts/start-windows.ps1 o scripts/start-windows.bat para crear el entorno virtual, instalar dependencias y arrancar el servidor.

Usa rutas locales como C:\Sites\example.com. Para SSH/SFTP habilita OpenSSH Client en Windows y configura el acceso por llave o contraseña desde Deploy remoto.

Redactor SEO

El redactor SEO ayuda a crear contenido con título, keyword, tono, audiencia y llamada a la acción. Es útil para páginas de servicios, páginas locales, landing pages y mejoras de contenido existente.

Security Scan

El escaneo de seguridad revisa señales pasivas del dominio: DNS, HTTPS, TLS, HSTS, cabeceras de seguridad y tecnología expuesta. No ejecuta ataques ni pruebas intrusivas. Sirve para monitorear la postura básica del sitio y ver progreso en el historial.

Search Console

La integración con Google Search Console muestra rendimiento orgánico, páginas principales, keywords y oportunidades SEO. Desde esas oportunidades se pueden crear nuevas páginas o pedir contenido a la IA.
